# 📌 LinkedList Console Application (Java)

A menu-driven Java console application that demonstrates the implementation of a Singly Linked List from scratch.
This project allows users to perform common linked list operations interactively using a command-line interface.

## 🚀 Features

The application supports the following LinkedList operations:

✅ Insert node at the beginning (HEAD)

✅ Insert node at the end (TAIL)

✅ Insert node at a specific position

❌ Delete node from the beginning

❌ Delete node from the end

❌ Delete node from a specific position

🔍 Search an element in the linked list

📄 Display all elements in the linked list

🚪 Exit the application safely
